# AIShot 1.11.2 검증 기록

- 대상: 1.11.2 / build 18, macOS 14 이상, Apple Silicon·Intel universal.
- 검증 환경: macOS 27.2.1, M2 Max, 2560×1440(2x) 화면 하나, 실제 사용 중인 맥.
- 목적: 속도 개선. 그 과정에서 찾은 결함 수정 포함.

## 바뀐 것과 측정값

| 항목 | 1.11.1 | 1.11.2 |
|---|---|---|
| 캡처 후 붙여넣기 도착 (목적지가 맨 앞) | 645–674ms | 590–605ms |
| 텍스트 복사(⌘⇧1) 클립보드 도착 | 360–389ms | 220–280ms |
| 꺼져 있는 목적지 앱으로 보내기 | 10초 뒤 포기 (클립보드만) | 약 1.2초에 붙여넣기 |
| 스크롤 캡처, 150행 시험 페이지 | 10.3초 | 7.1초 |
| 스크롤 캡처 종료 → 클립보드 | 약 3.5초 | 0.3–0.6초 |
| 스크롤 캡처 이음매의 검은 모서리 (6프레임) | 5곳 | 0곳 |
| 스크롤 OCR, 폭 1312–3840px 페이지 8개 | 2726줄 중 2505줄 | 2697줄 |
| 스크롤 OCR, 폭 5120px 페이지 | 226줄 중 0줄 | 222줄 |

- 붙여넣기: 포커스 복귀 대기 0.3초를 screencapture 종료 시각부터 센다(`--captured-at`).
  남은 고정 대기(0.3 + 0.12 + 0.08초)는 안전하게 검증할 방법이 없어 그대로 뒀다.
- 꺼진 목적지: `NSRunningApplication`의 `isFinishedLaunching`은 런루프가 돌아야 갱신되는데
  `usleep`으로 기다리고 있었다. 1.5초 걸려 뜨는 시험 앱에서 4초를 자도 false, 런루프 한 번
  돌리면 true. 런루프를 돌리며 기다리고, 첫 창이 생길 때까지(최대 5초) 더 기다린다.
- 텍스트 복사: 단축키와 함께 작업자를 띄워(`--ocr-standby`) 드래그하는 동안 인식기를 불러
  두고, 캡처 경로는 표준 입력으로 넘긴다. 캡처 잠금은 완료 표시를 띄우기 전에 푼다.
- 스크롤 캡처: 창이 움직였다가 두 번 연속 같은 화면이면 바로 다음으로 넘어간다. 움직이지
  않은 창은 전과 같이 0.28초를 기다린 뒤에야 "끝"으로 본다. 완료 표시는 띄워 둔 채 전달한다.
- 이음매: 각 프레임 아래쪽의 둥근 모서리(현재 macOS 창에서 30px)와 아래에 떠 있는 바가
  이음매마다 남던 것을, 다음 프레임이 같은 줄을 덮어 그리도록 고쳤다. 1.11.1 이전부터 있던
  결함이다.
- 스크롤 OCR: Vision은 폭 약 4000px 이상인 조각에서 오류 없이 글자를 일부 또는 전부
  빠뜨린다. 3840px 넘는 캡처는 폭 방향으로 겹치는 창으로 나눠 읽고, 조각 높이는 2400px
  이하로 하고, 내용이 있는데 한 줄도 안 읽힌 구간은 따로 다시 읽는다. 인식 시간은 약 27% 늘었다.

## 검증

단위 테스트(화면 없이 실행):

- `tests/stitch` 7건(신규): 1.11.1 코드로는 6건 실패, 1.11.2로 전부 통과.
- `tests/scroll-settle` 7건(신규), `tests/text-layout` 18건: 통과.

설치본 시험. 사용자가 자리를 비웠고 마이크를 쓰지 않을 때만, 합성 입력으로 수행:

1. 붙여넣기·꺼진 목적지: 붙여넣기를 기록하는 시험 앱을 목적지로 지정. 위 표의 값.
2. ⌘⇧1 → 영역 드래그: 호스트가 띄운 대기 작업자가 0.35–0.43초에 텍스트를 복사(로그 기준).
   Esc로 취소하면 대기 작업자가 종료. 완료 표시가 떠 있는 동안 다시 ⌘⇧1을 누르면 바로 시작.
3. 스크롤 캡처: WebKit 시험 창에 띄운 위키백과 문서 두 개. 영문 6프레임 2200×7622, 한글
   14프레임 2200×17607. 좌우 가장자리의 어두운 픽셀을 훑어 이음매 흔적 0곳 확인. 페이지의
   `innerText`와 OCR 결과를 대조해 빠지거나 겹친 문단 없음.
4. 스크롤 캡처 후 시험 앱에 경로 붙여넣기: 마지막 프레임 0.68초 뒤 도착.
5. 릴리스 zip(GitHub 자산과 SHA-256 일치)을 `--install`로 설치한 뒤 `--self-test` 정상,
   ⌘⇧1 텍스트 복사 재확인.

## 확인하지 못한 것

- Claude·ChatGPT 등 실제 앱이 꺼져 있을 때의 자동 실행 후 붙여넣기(시험 앱으로만 확인).
- Safari·Chrome 본체 창의 스크롤 캡처(같은 엔진의 시험 창으로만 확인).
- 실제 앱에서 아래에 떠 있는 바가 있는 창(단위 테스트로만 확인). 반투명한 바는 프레임마다
  픽셀이 달라 감지되지 않으므로 전과 같이 남는다.
- 배율이 다른 모니터 두 대에서의 스크롤 캡처 배율, 창 선택 화면의 입력 끊김 복구.
- Sparkle 자동 업데이트 경로(1.11.1 → 1.11.2). 이 맥에는 zip으로 직접 설치했다.

# AIShot 1.12 검증 기록

- 2026-11-27 · 빌드 19 · macOS 27.2.1 · iPhone 15 Pro
- 기능 커밋 `1988a54`, 배포 태그 `v1.12` (`47ab86a`), appcast 커밋 `f8d5e0f`
- [GitHub 릴리스](https://github.com/techjuicelab/aishot/releases/tag/v1.12)

## 실기기와 화면

- **AI용 최적화** 설정에서 iPhone으로 촬영한 JPEG 790,763바이트가 테스트 창에 실제 삽입됐다.
- **직접 설정**에서 긴 변 1,000px, JPEG 72%로 설정했다. 1,920×1,440 원본을 유지하면서 테스트 창에 1,000×750 JPEG 사본(161,017바이트)이 삽입됐다.
- 별도 실기기 글자 사진에 AI용 최적화를 적용했다. 기존 이미지 붙여넣기 PNG가 3,081,134바이트였고, 원본과 동일한 최적화 JPEG는 737,296바이트였다. 원본에서 인식한 43줄이 모두 유지됐다.
- iPhone에서 카메라 화면이 사라진 한 번의 시도는 Mac에서 90초 타임아웃으로 끝났다. 이때 파일과 클립보드는 유지됐다. 이후 시스템 패널의 표시 상태를 감시하고 Mac에 취소 대기 창을 추가했다.
- 수정 빌드의 실제 메뉴 막대 호스트에서 `⌥⌘P`를 누르자 Apple 연속성 카메라 패널이 열렸다. Mac의 Cancel 버튼을 눌러 워커 종료와 클립보드 유지를 확인했다. 시스템 창이 없는 상황에서 AIShot 자체 대기 창으로 취소하는 경로는 실기기에서 재현하지 못했다.
- **설정 → iPhone 사진**에서 저장 품질 **원본 크기**, 붙여넣기 품질 **AI용 최적화**를 저장했다. 공개 빌드를 설치한 뒤 실제 설정 창을 다시 열어 두 값과 **단축키 → iPhone으로 사진 찍기 → ⌥⌘P**를 확인했다.

## 자동 검증과 설치

- 스크롤 합성 7건, 스크롤 안정화 7건, 텍스트 배치 18건, iPhone 사진 13건 통과.
- Apple Silicon·Intel 빌드와 엄격한 코드 서명 검증 통과.
- 공개 ZIP·DMG의 SHA-256과 크기가 GitHub 릴리스 및 appcast와 일치했다. DMG 검증도 통과했다.
- 공개 ZIP으로 `/Applications/AIShot.app`을 빌드 19로 갱신했다. 메뉴 막대 LaunchAgent, 기존 화면 기록·손쉬운 사용 권한, 공개 ZIP과 설치 실행 파일의 일치를 확인했다.
- `main`의 Vercel 배포 성공을 확인했다. 이 설치에서는 수동 ZIP 설치를 사용해 Sparkle 자동 업데이트 경로는 검증하지 않았다.
